## 1. Definition of Workflow

| Колонка | Картка потрапляє сюди, коли | Картка виходить звідси, коли |
| --- | --- | --- |
| Backlog | Визначено тему та сформовано назву робочого кроку з розробки навчальних матеріалів чи документів. | Для картки сформульовано чіткий критерій завершення та вона готова до взяття в роботу. |
| Ready | Зрозуміло, що вважається її завершенням, вона розбита до розміру 1–2 днів і немає блокуючих залежностей. | Звільнився ліміт ємності в колонці In progress і виконавцем розпочато її виконання. |
| In progress | Виконавець безпосередньо приступив до виконання завдання та перевів картку з Ready. | Первинний проєкт документу чи коду завершено й сформовано файл або пул-реквест для вичитання. |
| Review | Результат можна прочитати або відкрити за посиланням у репозиторії для вичитання. | Усі зауваження виправлено, документ відповідає вимогам і закомічено в основну гілку. |
| Done | Картка повністю виконана за критерієм готовності, а відповідні файли збережено в репозиторії. | Кінцевий стан (картка лишається в колонці як архів виконаного). |
